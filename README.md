# GeoGuessr Atlas

Тёмный многостраничный атлас для изучения стран по визуальным признакам GeoGuessr.

## Сейчас в проекте
- Адаптивная главная страница.
- Интерактивная карта мира с масштабированием и выбором стран.
- Каталог флагов с поиском по русскому и английскому названию.
- Раздел общих признаков.
- Мобильная вёрстка.

## Важно
Эта стартовая версия пока использует внешние источники для карты, библиотек и изображений флагов. Для полной автономности необходимо добавить SVG/PNG флаги в `assets/flags/` и заменить ссылки на локальные файлы. Данные каталога пока содержат начальный список, а не окончательные 200 стран.

## Публикация через GitHub Pages
1. Открой Settings → Pages.
2. В разделе Build and deployment выбери Deploy from a branch.
3. Branch: main; folder: /(root).
4. Нажми Save. После публикации сайт будет доступен по адресу `https://rubcova673.github.io/geoguessr-atlas/`.

## Структура
- `index.html` — интерфейс
- `style.css` — тёмная адаптивная тема
- `app.js` — карта и каталог
